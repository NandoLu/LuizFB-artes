# Portfólio de Artista - Luiz Fernando Balbino

Este é o meu portfólio online e Linktree pessoal, desenvolvido para apresentar meus trabalhos como artista plástico e facilitar o acesso às minhas plataformas sociais e de contato.

**Funcionalidades:**

* **Página Centralizada:** Um hub único para conhecer minha arte e presença online.
* **Links Diretos:** Botões de acesso rápido para:
    * WhatsApp
    * TikTok
    * Instagram
    * YouTube
    * GitHub
    * LinkedIn
* **Galeria de Trabalhos:** Uma seção dedicada para exibir miniaturas dos meus projetos de pintura e desenho.
* **Design Responsivo:** O layout é totalmente adaptado para oferecer a melhor experiência em dispositivos móveis e desktops.

**Tecnologias Utilizadas:**

* HTML5
* CSS3
* Font Awesome (para ícones sociais)

Sinta-se à vontade para explorar meus trabalhos e conectar-se comigo!
